# Communication & Working Style
- Wants each task verified before the next one starts ("verify each one before moving on to the other", "After each completion, verify, then proceed with the next"). Confidence: 0.9
- Prefers terse, stripped-down replies; enabled the "caveman" personality as the default on all profiles so he doesn't have to invoke it per chat. Confidence: 0.85
- After work is done, expects a plain-language summary of what changed and how to test it — sometimes explicitly in tabular form ("what was done … in simple terms", "summarize what was done and how to test it"). Confidence: 0.9
- Reacts badly to scope creep and over-narration; when he names one small change he wants exactly that change ("Why is it so hard? bro, all I ask is to reduce the button height … That's it/"). Confidence: 0.85
- Prefers the agent to make the recommended call and keep going rather than stopping to ask, especially when he is away or asleep ("I give you all permissions … for any questions, just do what you recommend"; "Continue with the rest … as I'm going to sleep"). Confidence: 0.9
- Asks to be reminded about deferred items until they're actually done. Confidence: 0.6
- When reporting bugs, includes detailed browser console and network error logs (e.g. `net::ERR_CONNECTION_REFUSED`, 400 responses, stack traces). Confidence: 0.9
